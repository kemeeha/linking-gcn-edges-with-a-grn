# linking-gcn-edges-with-a-grn
This code will link the genes in a human GCN with a tissue specific human GRN to generate gene regulation mechanism hypotheses. One can use this mapping to explain why a GCN edge exists in the first place.
Clone this script here: https://github.com/kemeeha/linking-gcn-edges-with-a-grn/blob/main/GCN-GRN_linking.bash
